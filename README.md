# Nolan Colton — Portfolio Website

A clean, responsive personal portfolio built with **Next.js 13**, **Tailwind CSS**, and **TypeScript**.  
This site highlights my background, skills, and project work as a high school student and builder based in Cupertino.

![screenshot](./public/preview.png)

---

## 🚀 Features

- ✨ Sleek layout with Next.js App Router
- 🎨 Tailwind CSS for custom styling
- 📷 Profile section with dynamic layout
- 📬 Contact links using Font Awesome icons
- 🌐 Fully responsive for mobile & desktop
- 🖋️ Google Font integration with `@next/font`

---

## 🛠 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Font Awesome](https://fontawesome.com/)
- **Font:** [Figtree via `@next/font`](https://nextjs.org/docs/pages/building-your-application/optimizing/fonts)
- **Deployment:** [Vercel](https://vercel.com/)
